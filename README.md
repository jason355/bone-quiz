# 3D 骨頭跑台測驗 / 3D Bone Practical Quiz

Single-file interactive 3D bone spotter exam (繁體中文 + English). Open `index.html` — or the GitHub Pages URL — in a desktop browser (Chrome / Edge / Firefox; WebGL required). The first load is ~22 MB.

Live: `https://jason355.github.io/bone-test/`

Modes: 跑台考試 (exam), 自由練習 (practice), 探索模式 (Explorer). Syllabus coverage: see `COVERAGE.md`.
